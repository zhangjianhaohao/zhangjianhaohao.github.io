## Claude Code的安装

Window操作系统的话，官方推荐使用这个powershell。npm run 能解决很多这个路径问题

## 1.Claude Code的核心命令

```powershell
# Claude Code的命令
/

# 生成项目的.claude文件，读取项目，生成长期记忆的文件
/init

# 清除短期记忆（清除会话）
/clear

# 查看/导出聊天记录(简历)
/resume

# 进入终端命令
!

# 切换Claude Code的模式(三种模式)
shift+tab

```

### 默认模式

项目文件重要,还有追求安全，可控，都可以使用默认模式

### 自动模式

对项目熟悉，并且有明确的开发规范与目标，可以使用这个。他会自动修改文件
**什么时候使用**

- 对项目熟悉
- 有明确的目标
- 自动写多个模块
